# PetFinance

Сервис для учёта личных финансов: пользователи могут добавлять доходы и расходы и отслеживать свой баланс.

## О проекте

Pet-проект для практики связки **Go + PostgreSQL**. Бэкенд реализован на Go в виде REST API, есть простой фронтенд (HTML/CSS/JS) для взаимодействия с сервисом. Всё приложение упаковано в Docker для удобного локального запуска.

## Технологии

- **Backend:** Go, REST API
- **База данных:** PostgreSQL
- **Frontend:** HTML, CSS, JavaScript
- **Инфраструктура:** Docker, Docker Compose

## Запуск проекта

Для запуска необходимо установить Docker.

```bash
docker-compose build
docker-compose up -d
```

Приложение запустится в фоне. Автоматически поднимутся контейнеры с PostgreSQL и Go-приложением.
